EB28 Mission Control Support

EB28 Mission Control for iPhone is a companion to Mission Control running on your Mac. It needs an available paired Mac; it is not a standalone hosted task service.

Connect your phone

  1. Open Mission Control on your Mac and choose Phone.
  2. Enable phone access and scan the pairing code with the iPhone app. Allow camera access when using the scanner.
  3. Keep the Mac running and reachable on the same Wi-Fi. If you deliberately configure a private network such as Tailscale, both devices must have access to it.

Pairing codes contain access credentials. Do not send a code or screenshot of it to support or post it publicly.

Connection troubleshooting

  • Check that phone access is enabled on the Mac and that the Mac is awake, running Mission Control and reachable.
  • Allow Local Network access for the app in iPhone Settings. Allow Camera access if you want to scan a code.
  • Use More → Refresh now. If the Mac has generated a new code, unpair and scan the current code.
  • Calendar, agent, chief-of-staff, trading and pipeline data depend on services configured on the paired Mac. An empty view does not establish that those services are connected.

Disconnect and control access

Choose More → Unpair this phone and confirm to remove this phone's saved pairing credential and clear its current displayed data. On the Mac, Phone → New code invalidates the old code for all paired phones. Turning off phone access stops the Mac's phone listener.

Unpairing does not delete tasks, chat history, calendar records or agent logs on the Mac or in connected services. Manage those records on the Mac and with the relevant service.

Badges and connected services

The app can request permission to update its notification badge for work needing attention. Change notification permissions in iPhone Settings. Calendar data is supplied by the Mac's configured Google calendar integration; the iPhone companion does not request direct calendar access in this implementation.

Get help

Contact EB28 support at social@eb28.co.

When requesting help, describe the app and Mac versions, the affected screen and the error. Remove pairing codes, credentials and private task, calendar, chat or customer information from screenshots.
