## Description

Wake Up Ya Bish turns your morning alarm into a neon-retro command center for mornings that need more force than a polite clock.

Set the alarm, hit fast timers, check what is next, and keep a 67-day habit mission in view without digging through boring menus. The redesign keeps the loud synth console energy, but cleans up navigation so Home, Calendar, Habit, Profile, and Settings are easier to reach.

The app is built for people who want a wake-up system with a pulse: bright enough to notice, simple enough to use half-awake, and useful enough to help you move into the day instead of just snoozing through it.

What you can do:

- Set a daily wake-up alarm with native iOS AlarmKit delivery on supported iOS versions
- Launch quick timers for focus, breaks, naps, breathing, and grind sessions
- See a cleaner neon dashboard with the current time, alarm state, and next move
- Connect calendar access or paste a private calendar feed to keep upcoming events visible
- Build a daily habit streak with mission progress and recent completions
- Use the matching Settings and Profile panels to manage alarms, purchases, ad privacy, and calendar feeds
- Add premium matching Home Screen widgets for alarm status, habit progress, and quote of the day
- Remove sponsor panels with the optional Remove Ads monthly subscription

Wake Up Ya Bish keeps the weird retro bite, but the new layout is cleaner, easier to scan, and built around the controls you actually use every morning.

The free version includes sponsor panels. Remove Ads is an optional auto-renewable monthly subscription that cleans up the dashboard.
